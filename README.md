# Coloristia 🎨✨

**Coloristia** es un generador de paletas cromáticas profesional, diseñado para ofrecer una experiencia de usuario fluida, elegante y altamente funcional. Basado en una estética *glassmorphism*, permite crear, visualizar y guardar combinaciones de colores con precisión técnica.

## 🚀 Características

- **Generación Dinámica**: Crea paletas basadas en armonías Monocromáticas, Complementarias, Análogas y Tríadas.
- **Interfaz Premium**: Diseño moderno con efectos de cristal, desenfoques y animaciones suaves.
- **Navegación Inteligente**: Salto directo a paletas específicas y botón "ToUp" con detección de actividad.
- **Gestión de Usuarios**: Sistema de registro y guardado de paletas personalizadas.
- **Persistencia**: Tus colores se mantienen incluso después de recargar la página.

## 🛠️ Tecnologías

- **Frontend**: React, TypeScript, Vite, CSS Vanilla.
- **Backend**: Node.js, Express, Prisma, SQLite.
- **Auth**: JWT (JSON Web Tokens) y Bcrypt.
